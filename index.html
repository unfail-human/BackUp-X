서식 복사 사용법

티스토리 HTML 모드에 붙여넣어 주세요.
  1. BackUp-X에서 트윗을 불러오고 내용을 편집합니다.
  2. 서식 복사 버튼을 누릅니다.
  3. 티스토리 편집기 상단의 기본모드 → HTML을 선택합니다.
  4. 원하는 위치에 붙여넣은 뒤 다시 기본모드로 돌아옵니다.

복사되는 내용은 이미지가 아닌 HTML 서식이므로 티스토리에서 글을 수정할 수 있습니다. 프로필 사진은 티스토리의 이미지 보안 정책에 따라 표시되지 않을 수 있습니다.
